# 🚀 Crowdfunding Campaign Analysis Dashboard
## 📌 Project Overview

Crowdfunding has become a powerful way for creators and entrepreneurs to raise funds for innovative ideas. This project provides an in-depth analysis of crowdfunding campaigns to uncover funding patterns, campaign success factors, backer engagement, and category-wise performance.

Using SQL, Excel, Power BI, and Tableau, raw campaign data was transformed into interactive dashboards that help stakeholders understand what drives successful fundraising campaigns and make data-driven decisions.
## 🎯 Business Objective

The primary goal of this project is to analyze crowdfunding campaign data and answer key business questions such as:

Which categories attract the highest funding?
What factors contribute to campaign success?
Which countries generate the most pledges?
How do backers influence campaign outcomes?
What trends can help creators improve fundraising performance?
